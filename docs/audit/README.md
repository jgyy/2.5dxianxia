# Reproduced-defect ledger

The audit compared the merged baseline **`4c6493c`** with this change using the same two harnesses. Baseline source was extracted with `git archive` into a temporary directory, imported using Godot 4.7, and executed headlessly. Baseline files in this directory record observed results; final result files are regenerated by CI.

## Counts and their meaning

| Audit | Checks | Failed on baseline | Failed after fixes |
| --- | ---: | ---: | ---: |
| Save validation and preservation | 133 | 131 | 0 |
| Gameplay guards and prop collision | 197 | 196 | 0 |
| Combined | **330** | **327** | **0** |

These are reproducible failing cases, not 327 independent root causes. The 131 save failures include many field/type combinations, and 178 prop failures share the absent-collision cause. The remaining 18 failing gameplay cases exercise distinct entry points or behaviors. The audit does not establish 100 independent underlying bugs. Passing baseline cases are retained so the report does not count them as defects.

## What changed

- Save validation now checks numeric type, finiteness, integer fields, bounds, appearance, ending values, world identities, duplicates, coordinates, and plot consistency before changing state. Invalid loads leave progression and world consumption intact.
- Typed and versioned campaign progress includes validated prerequisites and reputation. Version-one migration provides deterministic missing appearance/stamina defaults. Atomic save replacement retains a backup and preserves a valid save when current state is invalid.
- Title and modal states block attacks, spirit palm, and rewards. Pause freezes movement, gravity, actor animation, and combat timers. Losing window focus pauses play.
- Interactions accept registered, nearby, unobstructed targets. Duplicate consumption and supplied reward dictionaries cannot grant additional items or qi. Full-health healing preserves herbs.
- Negative and non-finite hit/damage amounts are ignored. Respawn resets aim, timers, motion, and pursuing enemies.
- Ending selection requires the pending final choice and becomes immutable after selection. Saves, loading, travel, and other panels cannot replace that choice. Both Mercy and Ascension are checked independently.
- Physical world props now have collisions. Enemies use CharacterBody3D movement and local collision steering. Sight checks prevent sword, spirit, and enemy attacks through solid geometry.
- Effect playback uses a bounded pool, stale actors leave the registry, the compass follows yaw, and renewable regional resources keep gathering chains recoverable.

## Evidence and reproduction

`baseline-saves.json` and `baseline-gameplay.json` contain the original observations. `save-results.json` and `gameplay-results.json` contain the fixed observations. `ledger.csv` lists every originally failing case with its test ID and category. Save-case inputs are in `tests/save_cases.json`; the harness mutates one field at a time and checks both rejection and unchanged state.

```bash
godot --headless --path . --script tests/audit_saves.gd
godot --headless --path . --script tests/audit_gameplay.gd
```

For a baseline replay, extract `git archive 4c6493c` to a separate temporary directory, copy these two harnesses and `tests/save_cases.json` there, import that project with Godot 4.7, and run the same commands. The baseline is expected to return a nonzero status. Baseline malformed-type cases may also produce script errors; those errors demonstrate the missing validation. No actual player save is used: harnesses select dedicated `user://` test filenames.

`tools/check.sh` also runs the core adventure, independent Ascension/migration checks, the campaign regression suite, asset/content validators, and the exported-PCK smoke test. The campaign suite completes all 1,200 prerequisite chains, checks reward idempotence, verifies five objective kinds, visits every region, and uses actual actors/resources for journal acceptance, gathering, travel, rest, and persistence. CI rejects nonzero exits, engine errors, missing result markers, and any failed check.
